# Tielora final logo direction

This document takes the owner's four picks from `03-logo-evaluation.md` (Wordmark, Converge Lockup, TL Monogram, Hex Node) and turns each into a production-ready direction, then names the final direction and gives the exact recipe for building it in code.

Locked palette (unchanged): primary blue #2e5aac, ink #152647, mid #1f3d77, teal #46c4b0, text #4a4e57, gray #a9aeb8, stone #d8d2c4, page #f5f6f7. Never red. Type: Candara, falling back to Segoe UI, medium weight, sentence case, no exclamation marks.

Every Higgsfield prompt below is for Recraft V4.1 vector mode. Recraft misspells and distorts letters, so no prompt asks for a word; every wordmark is set in code. Append to each prompt: "flat vector, solid fills, no gradients, no 3D, no shadows, no texture, no mockup, centred, generous negative space."

## Pick 1: Concept 1, Tielora Wordmark

The name alone, in Candara medium, sentence case, tracking about plus 2 percent, one teal circle as the i-dot.

- **Primary logo.** Ink #152647 letters, teal #46c4b0 i-dot, on page #f5f6f7 or white.
  Prompt (layout reference only, letters are set in code): Wordmark layout study: a seven-letter word in a humanist sans-serif, medium weight, ink blue #152647, sentence case, the dot of the second letter drawn as a small teal #46c4b0 circle, white background #ffffff, flat vector, solid fills, no gradients, no 3D.
- **Secondary logo.** Same wordmark reversed: page #f5f6f7 letters, teal i-dot, on ink #152647.
  Prompt: Wordmark layout study reversed: a seven-letter word in a humanist sans-serif in near-white #f5f6f7 with one small teal #46c4b0 circle as an i-dot on a dark ink blue #152647 background, flat vector, solid fills, no gradients, no 3D.
- **Icon-only.** None. Where a symbol is needed, use the Converge mark (Pick 2).
- **Monochrome.** All ink #152647, i-dot included; or all #f5f6f7 on dark.
- **Light-background.** The primary.
- **Dark-background.** The secondary.
- **Favicon direction.** Not the wordmark. The teal i-dot alone is too weak at 16 px; the Converge mark is the favicon.
- **App-icon direction.** Not the wordmark. Use the Converge mark on a primary blue tile.

- **Secondary logo.** Stacked: hexagon centred above the wordmark, hexagon width equal to twice the cap height.

- **Icon-only.** The hexagon alone.
- **Monochrome.** All ink #152647.
  Prompt: Single colour logo in ink blue #152647 on white #ffffff: a heavy regular hexagon outline with a solid circle at the centre joined by three lines to alternating corners, no text, flat vector, solid fills, no gradients, no 3D.
- **Light-background.** The primary.
- **Dark-background.** Outline and spokes #f5f6f7, node #46c4b0, on ink #152647.

## Recommended final direction

**Concept 6, the Converge mark with Concept 1's wordmark.** The Converge symbol is the brand's icon everywhere a symbol is needed (favicon, app icon, avatar, loading state), and the lockup is the symbol beside the Candara wordmark for the app header, landing page, email header and sales deck. TL Monogram and Hex Node stay in the drawer as alternates.

### Claude Code SVG recreation (step by step)

All coordinates are on a 512 by 512 grid, origin top left, y increasing downward.

1. **Canvas.** `viewBox="0 0 512 512"`, transparent background.
2. **Node.** Centre (256, 256). `circle r="52"`, fill #46c4b0. Draw it last so it sits on top of the spokes.
3. **Spokes.** Four straight lines from a point at radius 180 from the centre to the centre itself, stroke #2e5aac, stroke-width 40, `stroke-linecap="round"`. Angles are measured clockwise from 12 o'clock and are deliberately uneven (30, 120, 200 and 300 degrees) so the mark never reads as a crosshair. Outer end points, using x = 256 + 180 sin(angle) and y = 256 minus 180 cos(angle):
   - 30 degrees: (346, 100.1)
   - 120 degrees: (411.9, 346)
   - 200 degrees: (194.4, 425.1)
   - 300 degrees: (100.1, 166)
   Each line runs from its outer point to (256, 256); the node covers the join, so the spokes appear to stop at the node's edge.
4. **Proportions to keep.** Node diameter 104 is 2.6 times the stroke width 40. If either is changed, keep that ratio; it is what keeps the node readable at 16 px.
5. **Monochrome.** Same geometry, spokes and node both ink #152647 (light surfaces) or both #f5f6f7 (dark surfaces).
6. **Dark background.** Spokes #f5f6f7, node #46c4b0. Place on ink #152647 or mid #1f3d77.
7. **Clear space.** At least 40 px (one stroke width, about 8 percent of the mark) beyond the round ends of the spokes on every side. In the lockup the gap between the longest spoke end and the first letter is one cap height.
8. **Lockup wordmark.** `<text>` in `font-family="Candara, 'Segoe UI', sans-serif"`, weight 500, letter-spacing plus 2 percent of the font size, fill #152647, sentence case "Tielora". The mark is scaled to 0.5 (a 256 px symbol) and the type is 150 px so the cap height (about 96 px) sits at the symbol's optical centre; baseline at y 208 when the node centre is at y 160. The teal i-dot from Concept 1 is added when the wordmark is converted to outlines for production (replace the dot of the i with a `circle` in #46c4b0 of the same diameter as the stem width); the shipped `<text>` version leaves the dot in ink so it never mis-renders on a machine without Candara. Recraft misspells text, so the wordmark is always set in code, never traced from a render.
9. **App icon tile.** Wrap the dark version of the mark in a `rect` 512 by 512, `rx="112"`, fill #2e5aac, and scale the mark to 0.7 about the centre (`transform="translate(76.8 76.8) scale(0.7)"`).
10. **Export sizes and file names.** From `docs/brand/logos/final/`:
    - `favicon-16.png` (16 by 16, from `tielora-mark.svg`, transparent)
    - `favicon-32.png` (32 by 32, from `tielora-mark.svg`, transparent)
    - `apple-touch-icon-180.png` (180 by 180, tiled)
    - `icon-192.png` (192 by 192, tiled, PWA)
    - `icon-512.png` (512 by 512, tiled, PWA and store listing)
    - `tielora-mark.svg`, `tielora-mark-mono.svg`, `tielora-mark-dark.svg`, `tielora-lockup.svg` (the four hand-authored sources in this folder)
11. **Verify.** `python3 -c "import xml.etree.ElementTree as E; E.parse('docs/brand/logos/final/tielora-mark.svg')"` for each file, then open each at 16, 32 and 512 px in the browser before wiring it into `src/app/icon.svg` and the app header.
